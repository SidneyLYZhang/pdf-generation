# 分层随机化的坑

按渠道分层后做随机化，看着严谨，实际上如果渠道本身是实验的干预对象，分层就会引入选择偏差。判断标准很简单：**分层变量是否可能被实验改变**。

可行的做法是只在实验开始前就固定、且实验期间不可变的变量上分层，比如注册月份、首装版本。

# 样本量与最小可检测效应

最小可检测效应（MDE）与样本量的关系近似为 $n \propto \sigma^2 / \delta^2$。在实践中更常见的问题不是算不出样本量，而是**实验做完才发现样本量根本不够**。

一个粗略的经验值：日活三万的产品，做一次两周的实验，通常只能可靠检测 2% 以上的相对变化。

# 指标口径

::: {.notice}
留存的口径必须在实验开始前写死，并在实验期间不做任何调整。中途改口径的实验，结论一律作废。
:::

常用的三个口径：

- **次日留存**：安装后第二天启动。
- **7 日留存**：安装后第 7 天启动。
- **周活留存**：本周活跃、下周仍活跃。

# 代码片段

```python
import numpy as np

def mde(sigma, n, alpha=0.05, power=0.8):
    z_alpha = 1.96
    z_beta = 0.84
    return (z_alpha + z_beta) * sigma * np.sqrt(2 / n)
```

实践中最容易被忽略的是 `sigma` 的口径：它是**单用户指标的方差**，不是均值的方差。

::: {.warning}
如果每个用户的指标是「是否留存」这种 0/1 变量，`sigma` 应取 `sqrt(p * (1 - p))`，其中 `p` 是基线留存率。
:::

# 复盘清单

1. 实验前：写死口径、算好样本量、确认分层变量不可变。
2. 实验中：每日检查分流比例，偏差超过 1% 就暂停。
3. 实验后：先看整体，再分渠道，最后看长期留存。
