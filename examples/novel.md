# 初见

雨停得很突然。周野从便利店出来时，天已经黑透了，路灯把积水照成一片片碎掉的金子。他把伞收起来，抖了抖，水珠顺着伞骨往下掉，砸在鞋面上。

他不太确定自己为什么要来这里。这座城市他住了七年，熟悉到可以闭着眼睛走完三条街，可今晚的每个路口都像是第一次经过。

手机在口袋里震了一下，是气象台的消息：暴雨黄色预警解除。他盯着那行字看了几秒，然后按灭了屏幕。

# 信号

实验室在十一楼，这个点只剩走廊尽头的一盏灯还亮着。周野刷开门禁，听见服务器机柜低沉的嗡鸣，像某种缓慢的呼吸。

屏幕上是一条未读的日志：凌晨三点十七分，收波设备记录到一段持续四十一秒的窄带信号，频率在 1420 兆赫附近，强度很弱，但结构异常规整。

他放大波形，看了很久。

那不是噪声。

# 等待

接下来的三个月，周野几乎住在了实验室。他把那四十一秒切成上千个片段，逐段比对，逐段排除。天气、飞机、卫星、微波炉，所有能想到的干扰源都被他试过一遍。

答案是：都不是。

同事劝他别钻牛角尖：「说不定就是设备抽风。」他点头，第二天照旧来。他不是不知道这种可能性，他只是没办法把那段波形从脑子里删掉。

# 回声

第四个月的某个凌晨，信号又出现了。这一次持续了六十三秒，而且比上次更清晰。

周野没有叫人。他把录音存了三份，然后坐在椅子上，听着硬盘转动的声音，忽然想起很小的时候，父亲在阳台上架过一台老式收音机，深夜里全是沙沙的杂音。

父亲说，那些杂音里藏着很远的地方。

他不知道这次是不是。但四十一秒之后是六十三秒，六十三秒之后也许是别的什么。他愿意等。
