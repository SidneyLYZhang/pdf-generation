# 前言

这本书写给两类人：一类是每天盯着看板、却不知道从哪下手的产品经理；另一类是拿到了分析结论、却无法说服团队的数据分析师。

两类的困境其实是同一个：指标是结果，结果是不可直接操作的。要让它变得可操作，就必须往下拆，一直拆到「某个具体动作的完成率」。

这本书讲的就是这七次拆解。

## 阅读方式

七章之间大致是递进关系，但每一章也可以单独读。如果你只有一小时，建议读第三章和第五章——它们分别是「留存」与「渠道」的拆法，也是实践中最容易出错的地方。

每章末尾有一节「本章要点」，用几条短句概括。正文中的案例都做了脱敏处理，数字经过等比缩放，不影响结论的相对关系。
