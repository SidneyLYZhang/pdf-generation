# 执行摘要

本季度新增用户 48.7 万，环比增长 12.4%，但次日留存从 41.2% 下滑至 38.6%。下滑并非来自渠道质量，而是新版本首启引导把「跳过」按钮前置，导致新用户在前 30 秒内完成关键动作的比例下降。

三条结论：

- 新增结构变化：信息流渠道占比从 31% 升到 46%，但其 7 日留存低于自然量 9 个百分点。
- 引导路径变化：首启引导的完成率下降 14%，是次日留存下滑的主因。
- 付费转化稳定：付费率维持在 3.1%，ARPPU 提升 6.8%。

# 数据概览

## 核心指标

| 指标 | 本季度 | 上季度 | 环比 |
|------|--------|--------|------|
| 新增用户（万） | 48.7 | 43.3 | +12.4% |
| 次日留存 | 38.6% | 41.2% | −2.6pp |
| 7 日留存 | 21.4% | 22.8% | −1.4pp |
| 付费率 | 3.1% | 3.1% | 0.0pp |
| ARPPU（元） | 86.4 | 80.9 | +6.8% |

> 留存口径说明：次日留存以自然日计算，跨时区用户按设备本地时间归入当天，与上季度口径一致。

## 渠道效率

信息流渠道的获客成本为 18.2 元，低于应用商店的 26.5 元，但用户质量差异明显。把渠道按「首月 ROI」排序后，自然量的 ROI 是信息流的 2.3 倍。

# 问题定位

## 首启引导的漏斗

对比 2.3 与 2.4 两个版本的首启漏斗：

| 步骤 | 2.3 完成率 | 2.4 完成率 | 差值 |
|------|-----------|-----------|------|
| 启动 | 100% | 100% | 0 |
| 权限授权 | 92% | 90% | −2pp |
| 兴趣选择 | 78% | 66% | −12pp |
| 进入首页 | 74% | 61% | −13pp |

## 归因计算

用简单的差分法估计影响：若兴趣选择完成率维持 78%，按历史转化关系可推回约 2.1pp 的次日留存，与观测到的 2.6pp 下滑基本吻合，剩余 0.5pp 由国庆假期的季节波动解释。

# 建议

1. 把「跳过」按钮后置到第二步之后，并在兴趣选择页增加进度提示。
2. 信息流渠道设置首月 ROI 门槛，低于阈值的计划逐步减量。
3. 建立渠道质量分层看板，按周更新留存与付费的联合分布。

# 附录：口径与脚本

指标计算使用仓库内的 `metrics.py`，核心逻辑如下：

```python
def retention(cohort, day):
    base = cohort[cohort["day"] == 0]["uid"].nunique()
    alive = cohort[cohort["day"] == day]["uid"].nunique()
    return alive / base if base else 0.0
```

所有指标在口径变更时会在 `metrics.yaml` 中记录版本，历史数据不回溯重算。
