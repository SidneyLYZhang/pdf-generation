# 指标的定义

在讨论任何分析方法之前，先把指标定义清楚。一个定义不清的指标，会让后面所有的计算都失去意义。

::: {.definition title="留存"}
留存是指在某一时点新增的用户中，经过 $n$ 天后仍然活跃的比例。记第 $i$ 天新增用户集合为 $U_i$，第 $i+n$ 天仍活跃的子集为 $A_(i,i+n)$，则
$R_n (i) = |A_(i,i+n)| / |U_i|$。
:::

定义中有两个容易被忽略的细节：分母是**新增**用户而不是活跃用户；活跃的判断需要明确是「启动」还是「完成关键动作」。

::: {.theorem title="留存与样本量"}
若基线留存率为 $p$，则要在显著性水平 $\alpha$ 下检测相对变化 $\delta$，所需样本量约为
$n \ge 2 (z_{1-\alpha/2} + z_{1-\beta})^2 p (1-p) / (p\delta)^2$。
:::

::: {.proof}
略。该式由两比例检验的方差近似得到，推导见附录 A。
:::

::: {.example}
某产品基线次日留存为 40%，希望检测 5% 的相对提升（即 40% → 42%），取 $\alpha = 0.05$、$\beta = 0.2$。代入上式得每组约需 2.3 万新增用户。
:::

# 实验设计

## 随机化的层次

随机化的最小单位决定了实验能回答什么问题。按用户随机化可以回答用户体验问题，按设备随机化则可能污染同一用户的多设备行为。

::: {.notice}
如果实验的干预会影响同一用户的不同设备，就必须按用户而不是按设备随机化。
:::

## 常见陷阱

1. **样本比例失衡**：分流比例偏离设计值 1% 以上，先查分流逻辑。
2. **指标漂移**：实验中途修改口径，结论作废。
3. **多重比较**：同时看 20 个指标，总有一个显著。

::: {.warning}
第三种陷阱最隐蔽：它不会让结果「看起来错」，反而会让结果「看起来很好」。
:::
