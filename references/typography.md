# 排版原则

这份文档是排版的**唯一可执行规范**。`docs/总排版原则.md` 与 `docs/细节排版原则.md` 是它的出处与论证——读它们理解「为什么」，读这里知道「构建会怎么判」。两处说法冲突时，以本文档的口径段为准。

## 优先级

**机构/期刊规范 > 这份规范 > 用户明确要求 > Kind 默认值。**

用户可以直接要求「标题再大一点」「版面再紧一点」，但需求要落在这份规范之内：越界的部分要么换成规范内的最近邻，要么留下偏离记录。前两级之外没有第三个出口。

## 两档强制

- **阻断**：自相矛盾的设定——同一件事被两种手段重复表达。构建以退出码 1 拒绝，并指出该改哪个旋钮。
- **警告**：数值落在舒适区间之外。构建照常完成，但这条警告必须写进交付时的排版方案；它不是可以忽略的噪音。

## 口径

原则文档有几处会被读出两种意思，这里钉死。区间本身见上表，本文不复述数字——两处写同一个数，迟早会分叉。

**行距倍数** =（行盒 + leading）÷ 字号，**不是** 1 + leading。Typst 的 `par(leading:)` 只是行与行之间的额外距离，行盒由字体度量决定，实测值如下（换字族要重测，不是猜）：

<!-- BEGIN generated: metrics -->
| 字族 | 行盒 |
|------|------|
| `Libertinus Serif` | 0.658em |
| `Noto Serif SC` | 0.727em |
<!-- END generated: metrics -->

用 `1 + leading` 会得出偏大的假象。换用表里没有的字族时，这项检查降级为一条提示，不猜数。

**标题字号比**只约束一级标题。二三级靠字体族与字重分层：标题用 Noto Sans SC、正文用宋体，本身已经是两种区分，不必让字号继续翻倍。

**字体按用途计数**：正文中文一族、正文西文一族、等宽一族，这已经用满「≤3 种」的额度；标题族不计入，但必须全篇唯一。

**行距与每行字数**：中文用中文区间，西文用西文区间，都在上表里。西文**行距**没有区间——原则只给了中文的，所以西文行距不做判断，构建会记一条提示说明跳过了。信函与便签按「一次读完」处理，不受每行字数约束。

## 场景与 Kind

原则文档只写了四个场景，七个 Kind 映射如下。没有专用场景规则的 Kind 只套通用原则——这是刻意的留白，不是遗漏：与其编一套没人审过的场景规则，不如让它按 Kind 默认值加通用原则走。

| 原则里的场景 | Kind | 该场景的具体要求 |
|--------------|------|------------------|
| 论文 | `article` | 宋体正文、黑体标题、图表编号、参考文献按目标规范 |
| 报告 | `report` | 结论前置、图表优先、单一强调色 |
| 小说 | `novel` | 衬线正文、首行缩进分段、不叠可见段距 |
| 技术教材 | `textbook` | 语义块分层、边注、代码等宽 |
| — 只有通用原则 | `letter` / `note` / `book` | 按 Kind 默认值加通用原则，不额外要求 |

## 偏离

```yaml
deviations:
  indent-and-spacing:
    source: standard   # 机构规范；用户授权写 user
    reason: 期刊模板要求段首缩进且段间空一行
```

- 只有**阻断**规则可以偏离。警告不阻断构建，消掉它没有意义——它要的是在排版方案里一句话。
- 记录写进 `<首个输入文件>.doc.yml`，同时写进生成的 `.typ` 头部，所以 `.typ` 被搬走或改名后仍认自己那条记录。
- `python scripts/build_pdf.py build doc.md --deviation "规则=原因"` 是写入的快捷方式，加 `--deviation-source standard` 把来源标成机构规范。它只负责写文件；放行的是读回来的记录，删掉记录，同样的 spec 又会被拒。

## 出处

数值与判断来自两份原则文档：`docs/总排版原则.md`（对比、对齐、重复、亲密性；留白；字体与层级；中文排版；结构与导航）与 `docs/细节排版原则.md`（层级一致、网格对齐、节奏、克制、单行字数、字体选择三步法，以及论文/报告/小说/技术教材四场景细则）。

两份原文之间有两处数值不一致——每行字数（25–40 与 25–45）与行距（1.4–1.75 与小说 1.5–1.75）。合并规则是「取两者都接受的区间，落到上表」：合并后的结果是构建实际使用的值，原文的那几个数字只用来解释分歧从哪来。
