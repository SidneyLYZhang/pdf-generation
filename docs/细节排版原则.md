> 出处与论证：本文是排版原则的原始论述，不是构建的判定依据。构建实际使用的取值与两档判定见 [references/typography.md](../references/typography.md)；两处冲突时以那份为准。

先讲**通用底层原则**和**字体选择方法**，再针对论文、报告、小说、技术教材分别给出具体规则。所有场景的具体参数都以通用原则为根，只是数值和侧重不同。

## 第一部分：通用排版原则（适配一切场景）

**1. 层级一致原则**

- 全文建立固定的层级体系（标题级别、正文、注释、引用），同级元素样式完全相同，全篇不得破例。
- 层级不超过 4 层；层级靠字号和字重区分，不靠花哨装饰。

**2. 网格与对齐原则**

- 所有元素落在隐含的网格上：页边距统一、缩进统一、栏宽统一。
- 同一页面只用一种主对齐方式（通常左对齐或两端对齐），居中对齐仅用于标题、封面等极少数位置。

**3. 节奏原则（留白体系）**

- 间距必须成比例体系，例如：行距 1 单位 → 段距 1.5 单位 → 节间距 3 单位。间距越大的位置，分隔的内容层级越高。
- 页边距不小于版面宽度的 8%～10%，四周留足呼吸空间。

**4. 克制原则**

- 字体 ≤ 3 种（中文、西文、等宽各一算一种）；强调手段 ≤ 2 种（通常是粗体 + 一种颜色）。
- 重点内容占比不超过全文的 5%。

**5. 单行字数原则**

- 中文每行 25～45 字、西文每行 50～75 字符为舒适区。超出即分栏或加大页边距。

**6. 功能优先原则**

- 排版的唯一评判标准是"读者能否毫不费力地获取信息"，一切美化让位于此。

## 第二部分：字体选择的通用方法

字体选择按三步走：**定用途 → 定气质 → 定搭配**。

**第一步：按用途筛选**

| 用途            | 字体类型           | 原因                                   |
| --------------- | ------------------ | -------------------------------------- |
| 长文正文        | 衬线体（宋体类）   | 笔画有起落，引导视线水平移动，长读不累 |
| 屏幕阅读/短文本 | 无衬线体（黑体类） | 笔画均匀，低分辨率下清晰               |
| 标题            | 黑体或加粗衬线     | 需要视觉重量，拉开层级                 |
| 代码/数据       | 等宽字体           | 字符对齐是功能需求                     |

**第二步：按气质匹配**

- 宋体系（思源宋体、方正书宋）：典雅、正式、书卷气——适合论文、小说、公文。
- 黑体系（思源黑体、苹方、微软雅黑）：现代、中性、清晰——适合报告、教材、屏幕展示。
- 楷体/仿宋：传统、温和——仅适合引文、批注等局部点缀，不宜作正文。
- 书法体、美术体：只用于封面和标题装饰，正文禁用。

**第三步：搭配规则**

- 中西文搭配：中文宋体配西文衬线（Times New Roman、Source Serif），中文黑体配西文无衬线（Arial、Helvetica、Source Sans）。**气质必须一致**，不要宋体配 Arial。
- 字号对比：标题字号至少是正文的 1.3 倍以上，形成明确层级。
- 字重即层级：同一家族内用 Regular / Medium / Bold 分级，比换字体更优雅。
- 中英混排时西文字号通常比中文小 0.5～1pt，视觉大小才一致。

## 第三部分：分场景原则

### 1. 论文（学术写作）

核心诉求：**规范性 > 美观**，投稿模板的要求永远优先于个人审美。

- **结构刚性**：标题—摘要—关键词—正文—参考文献，编号体系（1 / 1.1 / 1.1.1）全篇统一。
- **正文**：宋体小四（12pt）或五号（10.5pt），1.5 倍行距，首行缩进 2 字符。
- **标题**：黑体分级，一级标题四号加粗，逐级递减；标题与上文间距大于与下文间距。
- **图表**：全文统一编号（图 1、表 2），图题在图下方、表题在表上方，图表必须能在脱离正文时被独立读懂（自明性）。
- **公式**：居中，编号右对齐；变量斜体、函数与单位正体。
- **参考文献**：严格按目标期刊/学校格式（GB/T 7714、APA 等），这是论文排版的第一优先级。
- 每页页眉页脚只放必要信息（页码、章节名），保持版面冷静。
- **禁忌**：彩色强调、艺术字、阴影——学术版面一律拒绝。

### 2. 报告（工作汇报 / 咨询报告）

核心诉求：**信息密度与阅读效率**，读者往往是时间稀缺的决策者。

- **结论前置**：每页一个核心观点，标题直接写结论（"Q3 营收同比增长 23%"），而不是写主题（"营收情况"）。
- **模块化版面**：封面—摘要—目录—正文—附录，每节首页有明显的章节标识。
- **正文**：黑体系（思源黑体、微软雅黑）10.5～11pt，行距 1.4～1.5 倍；正文也可考虑宋体，但图表页保持黑体。
- **图表优先**：能用图就不用表，能用表就不用段落；图表统一配色（主色 ≤ 3 种，来自企业 VI 色最佳）。
- **数据强调**：关键数字用大字号 + 强调色单独呈现（KPI 大字报式处理），一份报告一个强调色。
- **页边距**可以比论文小，但每页信息要有明确的视觉焦点。
- 附录与正文用明显的分隔页隔开，正文只放支撑结论的内容。

### 3. 小说（文学读物）

核心诉求：**沉浸感**，排版要"隐身"——读者读完全书都不该注意到排版的存在。

- **字体**：正文只用衬线体（宋体/明朝体），10.5～11pt；黑体在小说正文中是灾难。
- **行距**：1.5～1.75 倍，行距偏大一点更利于长时间阅读。
- **每行字数**：严格控制在 25～35 字（32 开书约 26 字/行是中文出版黄金标准）。
- **段落**：首行缩进 2 字符，**不加段距**——小说靠缩进而非空行分段，空行会打断叙事流。
- **对话**：换行分段，不滥用引号样式变化。
- **章节**：每章另起一页，章节标题页大量留白（标题位置在页面上 1/3 处是经典做法）。
- **场景转换**：节内场景切换用空一行或居中的小装饰符（※ 或 ···），全书只用一种。
- **页眉**：单页书名、双页章节名（或反之），页码放页脚外侧。
- **禁忌**：两端强制对齐造成的字距拉伸（中文应允许末行自然不齐）、加粗强调、彩色——小说里强调靠文字本身。

### 4. 技术教材 / 教程

核心诉求：**可检索性 + 可操作性**，读者不是顺序读完，而是跳着查、照着做。

- **信息类型分层**：正文讲解、代码、操作步骤、提示框、警告框——每种类型有固定且全篇一致的视觉样式（底色块、图标、边框）。
- **代码**：必须用等宽字体（JetBrains Mono、Fira Code、Sarasa Mono），浅灰底或带边框的代码块，必要时加行号和语法高亮；代码字号可比正文小 0.5～1pt。
- **操作步骤**：编号列表，一步一个动作，动词开头（"点击""输入"），步骤与截图就近放置。
- **导航系统最强**：页眉显示章/节名，页码醒目，目录做两级以上；术语表、索引放在书末。
- **概念—示例成对出现**：每个抽象概念紧跟一个可运行的例子，二者用样式区分但视觉绑定（间距靠近）。
- **重点标注体系**：定义、定理、技巧、易错点分别用固定图标或色块，但全书色彩不超过 2 种。
- **留白用于练习**：如果是教学用书，可以在章节末尾留空白区域供笔记。
- 每章开头放学习目标，结尾放小结与练习，结构全篇重复——教材靠结构重复降低学习负担。
